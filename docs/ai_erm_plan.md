# AI 전사 자원관리·컨설팅 플랫폼 개발 기획서 (AI-ERM)

1. 프로젝트 개요
프로젝트명

AI Enterprise Resource Management & Consulting Platform

가칭:

AI-ERM
AI 전사 자원관리 및 경영 컨설팅 시스템

핵심 개념

프로젝트 담당자가 데이터를 입력한다 → 전사 데이터가 통합된다 → AI가 분석한다 → 자원 배분을 최적화한다 → 문제를 예측한다 → 담당자와 경영진에게 실행방안을 제시한다.

즉,

사람은 데이터를 입력하고, AI는 회사를 분석하고 관리한다.

2. 개발 목적

기업에서는 프로젝트가 여러 개 동시에 진행되면서 다음과 같은 문제가 발생한다.

어떤 프로젝트에 인력이 부족한지 알기 어려움
직원별 업무량 파악이 어려움
자재 발주 시점 판단이 어려움
프로젝트별 원가를 실시간으로 알기 어려움
외주업체 관리가 분산됨
프로젝트 일정 지연을 사전에 발견하기 어려움
특정 직원이나 장비에 업무가 집중됨
프로젝트 간 자원 충돌 발생
경영진이 현장 데이터를 즉시 확인하기 어려움

이를 AI가 통합 관리한다.

22. AI의 5단계 역할

단순 챗봇으로 만들면 안 된다.

LEVEL 1 — 질문

사용자가 질문

LEVEL 2 — 분석

AI가 회사 데이터를 분석

LEVEL 3 — 진단

문제의 원인을 찾음

LEVEL 4 — 추천

해결책을 제안

LEVEL 5 — 실행지원

사용자의 승인 후

담당자 변경
일정 변경
구매 요청
업무 생성
알림 발송
보고서 생성

등을 실행한다.

일반 ERP:

프로젝트를 관리한다.

이 시스템:

회사의 데이터를 이해하고 앞으로 무엇을 해야 하는지 제안한다.

즉,

기존 ERP

What happened?

What is happening?

Why?

What will happen?

What should we do?

까지 제공한다.
